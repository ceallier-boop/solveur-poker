                  Importer mes mains

                  Tes fichiers restent sur cet appareil. Rien n'est envoyé. Les pseudos ne sont jamais conservés.

                  Choisis les fichiers d'historique de mains écrits par le logiciel Winamax sur ton ordinateur.

                  Aide : où trouver mes historiques ?
                  • Sous Windows, colle %APPDATA%\winamax dans la barre de l'explorateur, puis ouvre documents › accounts › ton compte › history.
                  • Si le dossier n'est pas là, le logiciel Winamax l'indique dans ses réglages de l'historique des mains.
                  • Prends les fichiers .txt des Expresso. Les fichiers qui finissent par _summary sont ignorés tout seuls.
